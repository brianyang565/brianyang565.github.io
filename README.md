# brianyang565.github.io

Source for the personal website of Brian Yang, published at <https://brianyang565.github.io>.

The site is built with Jekyll on GitHub Pages from the [Academic Pages](https://github.com/academicpages/academicpages.github.io) template, which is a fork of the [Minimal Mistakes](https://mmistakes.github.io/minimal-mistakes/) theme. Both are available under the MIT license.

## Where the content lives

- `_config.yml`: site settings and the sidebar profile
- `_data/navigation.yml`: links in the top menu
- `_pages/about.md`: home page
- `_pages/cv.md`: CV page
- `_publications/`, `_talks/`, `_teaching/`, `_portfolio/` (side projects): one Markdown file per entry
- `images/profile.png`: sidebar picture

GitHub Pages rebuilds the site automatically after each commit to `master`.
